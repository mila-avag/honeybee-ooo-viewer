# Honeybee OOO viewer

Static page for the Honeybee L1 delivery and QC helper.

Open the hosted page: https://mila-avag.github.io/honeybee-ooo-viewer/#home

CSV mode works in the browser. Drop in a sender preview or a Redash CSV export. Nothing is uploaded.

Connected Redash mode (the saved queries) still needs the local proxy on your laptop. GitHub Pages only serves this file.
