Link check

Drop a delivery sheet. You get the model names, the links, and a flag for each side: OK, WRONG LINK, MISSING LINK, or NO LINK AVAILABLE.

A name with gpt needs https://chatgpt.com/s…. claude or fable needs https://claude.ai/share/. argon needs the public scale-cds-public-us-west-2 S3 host. gemini (and not argon) needs https://share.gemini.google/. A link that starts with [No trajectory link is NO LINK AVAILABLE. A blank link is MISSING LINK.

Merge files

Drop two or more CSVs in the order they should apply. Each task id appears once. The later file wins. New columns from later files are kept.

    Task upload

    Paste task ids, name the two models, and pick a credential mode. This runs query 400607 and downloads the upload CSV. Language is en_US on every row. Drop a test-accounts CSV to fill the two logins: a row never gets the same account twice, and an email is reused only after every other email has been used the same number of times. Accounts stay in this browser and are written only into the CSV you download. Environment and estimated turns stay blank. Download query saves the SQL if Redash is unavailable.

    Batch progress

    Tasks still pending, by model pair and review layer. Finished tasks and paused tasks are left out. Load saved result is the last Redash run. Recompute scans the project and takes about 10 minutes.

    Ultra deliveries

    Delivered means sent in the last 21 days, or completed in that window and never sent. Pending review is a task sitting at L8, L10, or L12. Still in attempt means it has not left the attempt layer. Minutes per task is the average of all time spent on the task. Model A minutes repeat on every row for that model.
